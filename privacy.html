位置情報の利用

Location Radio は、再生中に現在地の地域に合う話題を選ぶため、端末の位置情報を使用します。端末上で都道府県・市区町村・町名などの地域名に変換し、話題生成サーバーには緯度経度を送信しません。ラジオを終了すると継続的な位置情報の取得を停止します。位置情報の利用許可は端末の設定から変更できます。

話題生成に使う情報

地域名、選択したジャンル、直前の話題とそのセッションで扱った話題の情報を、話題生成サーバー経由で OpenAI に送信します。生成した内容の表示と読み上げに使用します。音声の読み上げは端末の機能で行います。

OpenAI API には応答の保存を無効にする設定で送信します。ただし OpenAI は標準設定で、不正利用の監視ログにプロンプトと応答を最大30日保持する場合があります。詳しくは OpenAI のデータ管理方針をご覧ください。

端末に保存する情報

興味ジャンルの設定と話題への評価は端末に保存します。これらはアプリを削除すると端末から消去されます。初回公開版ではアカウント登録、広告配信、行動解析は行いません。

サーバーと通信

話題生成サーバーはリクエスト本文を保存しません。濫用防止のため、通信元 IP アドレスを短時間のレート制限判定に使用します。サーバーの運営には Cloudflare を利用します。通信は HTTPS で行います。
