位置情報の利用

Location Radio は、現在地の地域に合う話題を選ぶため、端末の位置情報を使用します。開始画面で現在地を一度取得し、アプリを開いてラジオを再生している間は地域の変化を追います。一時停止中は継続的な位置情報の取得を止め、画面を離れるとラジオと位置情報の更新を終了します。端末上で都道府県・市区町村・町名などの地域名に変換し、サーバーには緯度経度を送信しません。位置情報の履歴は保存しません。位置情報の利用許可は端末の設定から変更できます。

話題生成に使う情報

地域名、選択したジャンル、直前の話題とそのセッションで扱った話題の情報を、当アプリの Cloudflare サーバー経由で OpenAI に送信します。生成した内容の表示と読み上げに使用します。

OpenAI API には応答の保存を無効にする設定で送信します。ただし OpenAI は標準設定で、不正利用の監視ログにプロンプトと応答を最大30日保持する場合があります。詳しくは OpenAI のデータ管理方針をご覧ください。

音声の読み上げ

音声設定では、端末の音声、Google Cloud Text-to-Speech、OpenAI の音声を選べます。Google または OpenAI の音声を選んだ場合、読み上げる台本と選択した声・話速を当アプリの Cloudflare サーバー経由で選択先に送信し、合成された音声を端末で再生します。台本には地域名が含まれることがあります。端末の音声を選んだ場合は、読み上げのために台本を Google または OpenAI へ追加送信しません。クラウド音声は AI による合成音声です。

再生を速くするため、合成した音声を端末に一時保存し、古い音声は削除します。各音声サービス側でのデータの取り扱いは、選択したサービスの規約と設定に従います。

天気に合わせた背景

背景の表示に使う天気を取得するため、端末で変換した市区町村名と都道府県名を当アプリの Cloudflare サーバーに送信します。サーバーは地域の中心点を Open-Meteo で検索し、その地点の現在の天気を取得します。端末の緯度経度や町名は天気サービスへ送信しません。天気の取得に失敗してもアプリは利用でき、背景は端末の時刻に合わせて表示します。天気データ提供：Open-Meteo。

端末に保存する情報

興味ジャンルの設定と話題への評価は端末に保存します。これらはアプリを削除すると端末から消去されます。初回公開版ではアカウント登録、広告配信、行動解析は行いません。

サーバーと通信

サーバーは話題生成・音声合成・天気取得のリクエスト本文を保存しません。濫用防止のため、通信元 IP アドレスを短時間のレート制限判定に使用します。サーバーの運営には Cloudflare を利用します。通信は HTTPS で行います。
